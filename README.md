# Tsukena

## このアプリについて

**「記録の手間を極限まで減らす」ことだけを考えた、自分専用の家計簿アプリ。**

家計簿は「つける」もの。でも、このアプリでは基本的につけない。

既存の家計簿アプリは多機能すぎて、記録が面倒になり続かない。
このアプリでは、カードやQR決済で払ったものは何もしなくても記録され、
現金で払ったときだけ Discord に一言送れば済む。

- 利用者：自分ひとり
- 目的：毎日使う道具（迷ったら「続けられるか」で判断する）
- 名前の由来：カードやQR決済は自動で記録されるので「つけない」。家計簿なのにつけなくていい、というこのアプリのいちばんの特徴を、名前にした

## 使い方のイメージ

### ある1日

**8:10 通勤途中、カードでコーヒーを買う（450円）**

→ **何もしない。**
カード会社から届く利用通知メールをアプリが読み取り、自動で記録する。
店名から「食費」に自動で分類される。

**12:30 現金でランチ（800円）**

→ Discord の bot に一言だけ送る。

```
ランチ 800
```

bot からの返事：

```
🍚 食費 800円 で記録しました（今月あと 32,000円）
```

カテゴリが違っていれば、返事に付いたリアクションをタップして直す。
急いでいるときは `800` だけ送ってもよい（「未分類」として記録され、あとでアプリから分類する）。

**19:00 帰りにQR決済でドラッグストア（1,280円）**

→ **何もしない。** コーヒーと同じく、自動で記録される。
初めて行く店なので分類に自信がなく、アプリの「確認待ち」に入る。

### ある1週間

**日曜 21:00 Discord に週のまとめが届く**

```
📊 今週のまとめ（9/22〜9/28）
支出合計：18,450円
カテゴリ別の上位：食費 9,200円 / 日用品 4,100円 / 交通 2,300円
今月の予算：あと 21,550円
確認待ち：2件 → アプリで確認してください
```

→ スマホアプリを開き、確認待ちの2件のカテゴリをタップで決める（数秒）。
一度直した店は次から自動で分類されるので、使うほど確認は減っていく。

**予算の80%を超えたとき（随時）**

```
⚠️ 今月の予算の80%を使いました（あと 10,000円）
```

通知が来るのは、予算の80%と100%を超えたときだけ。

### ある1か月

**月末 Discord に月のまとめが届く**

```
📅 9月のまとめ
支出合計：78,300円（予算 80,000円）
前月比：-4,200円
カテゴリ別：食費 32,100円 / 固定費 20,000円 / 日用品 9,800円 / ...
```

→ グラフや明細などの詳細は、スマホアプリで見る。

## 記録の入口3つの使い分け

| 入口 | 使う場面 | 自分がすること |
|---|---|---|
| 自動取り込み（Gmail） | カード・QR決済での支払い | 何もしない（確認待ちがあればアプリで分類する） |
| Discord の bot | 現金での支払い | 「一言 金額」を送る |
| スマホアプリ | 修正、確認待ちの分類、振り返り、収入の入力 | 必要なときに開く。収入（給与など）は入金日・金額・メモを入力する |

- カードとQR決済は手で入力しない。これで二重登録を防ぐ（アプリから入力するのは収入だけ）
- 日々の状況は Discord への通知で把握し、詳しく分析したいときだけアプリを開く

## 記録する項目

| 項目 | 入り方 |
|---|---|
| 日時（利用日） | 自動（メールの利用日時、または bot に送った時刻） |
| 支払日 | 自動（現金・QR決済は使った日、カードは締め日のルールから計算した引き落とし日） |
| 金額 | 自動、または bot に送った数字 |
| 店名・メモ | 自動（メールの店名）、または bot に送った一言 |
| カテゴリ | 自動で分類（自信がないものは確認待ち、または未分類） |
| 支払い手段 | 自動（メールの送り主、または bot なら「現金」） |

- 月の予算と月のまとめは、支払日で数える（「今月いくら出ていくか」を見るため）。週のまとめは利用日で数える

### カテゴリ（初期値）

食費 / 日用品 / 交通 / 娯楽 / 交際 / 衣服 / 医療 / 固定費 / その他

- 1階層のみ。アプリから追加や名前の変更ができる

## 初期設定

1. **Gmail との連携**
   - Gmail で、カード会社や決済サービス（楽天カード、PayPayなど）の利用通知メールに、専用のラベル（例：`家計簿`）を付けるフィルタを作る
   - アプリから Google アカウントを連携する（アプリが読むのは、そのラベルが付いたメールだけ）
2. **Discord への bot の追加**
   - 自分しかいないサーバーに bot を招待する（bot と DM を始めるため）
   - 記録は bot との DM に送る。週のまとめや予算の通知も、同じ DM に届く
3. **予算の設定**
   - 月の予算を全体で1つだけ決める（例：80,000円）
4. **カテゴリの確認**
   - 初期値のままでよければ何もしない。必要なら追加や変更をする
