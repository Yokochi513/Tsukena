プライバシー ポリシー

Tsukena（家計簿アプリ）／ 制定日: 2026年10月21日

Tsukena は、開発者が自分の家計を記録するために個人で作り、自宅のサーバーで動かしている家計簿のアプリです。 利用者は開発者本人だけであり、ほかの人へのサービスとしては提供していません。 このページでは、Google アカウント（Gmail）と連携したときに、どの情報をどのように扱うかを説明します。

1. Gmail から読み取る情報

Gmail の読み取り専用の権限（https://www.googleapis.com/auth/gmail.readonly）を使います。 Google の権限はラベルの単位に絞れないため、アプリの側で、利用者が指定したラベル（例: 「家計簿」）が付いたメールだけを問い合わせます。 それ以外のメールは読みません。メールの送信・変更・削除はしません。

読み取ったメールからは、次の情報だけを取り出します。

  • カードや決済サービスの利用日・金額・利用先（店名）
  • メールの送り主と件名（支払い手段の判定と、取り込めなかったメールの表示に使う）
  • メールの ID（同じメールを二重に記録しないために使う）

メールの本文そのものは保存しません。

2. 情報の使い道

取り出した情報は、家計簿の支出として記録し、利用者本人がアプリで確認・修正し、週や月の集計を見るためだけに使います。 広告、分析のための外部への提供、機械学習の学習には使いません。

3. 保存する場所

  • 記録は、開発者の自宅のサーバーにあるデータベースにだけ保存します。
  • Google から受け取った認証情報（リフレッシュトークン）は、同じサーバーの、サーバーの管理者だけが読めるファイルに保存します。
  • アプリとサーバーの間の通信は HTTPS で暗号化します。

4. 第三者への提供

Gmail から得た情報を、第三者に販売・提供・共有することはありません。 記録を取り込めなかったときなどの通知は、利用者本人の Discord にだけ送ります。通知には送り主と件名を含めますが、本文は含めません。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

Tsukena による Google API から受け取った情報の使用と、ほかのアプリへの転送は、 Google API Services User Data Policy （Limited Use の要件を含む）に従います。

6. 連携の解除と情報の削除

  • Gmail との連携は、Google アカウントの サードパーティ製のアプリとサービス からいつでも解除できます。解除すると、Tsukena はそれ以降メールを読めなくなります。
  • 記録した支出は、アプリからいつでも削除できます。

7. このポリシーの変更

扱う情報や使い道を変えるときは、このページを更新し、制定日の下に改定日を書きます。

8. 問い合わせ先

GitHub のリポジトリの Issues から連絡してください。
