# ADR-0003: スマホアプリは Flutter で開発する

- 状態: 採用
- 日付: 2026-09-30
- 更新日: 2026-10-13（Flutter 採用を決定）

## 背景

修正・確認待ちの分類・振り返りに使うスマホアプリの形態を決める必要があった（README「未決定」）。

## 選択肢

1. PWA
2. ネイティブアプリ

## 決定

2 を採用する。アプリはサーバーの REST API だけを呼び、Gmail・Discord とは直接やり取りしない。

2026-10-13 に、ユーザーの技術選定により実装フレームワークを Flutter（Dart）に決定した。
Flutter プロジェクトはリポジトリの `app/` 配下に置く。

## 結果

- 確認待ちの分類など、タップ中心の操作を端末に合った操作感で作れる。
- サーバーとアプリの境界が REST API に限られるため、サーバー側の設計はアプリの技術に左右されない。
- ビルドと端末への配布の手間が増える。対象 OS と配布方法は基本設計の残課題（R-5）として決める。
