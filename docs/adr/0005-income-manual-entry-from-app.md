# ADR-0005: 収入はスマホアプリから手で入力する

- 状態: 採用
- 日付: 2026-10-14

## 背景

月の集計を支払日で数えることにした（→ [ADR-0004](./0004-monthly-totals-by-paid-date.md)）。
目的は「今月いくら入って、今月いくら出ていくか」を見ることだが、これまでの設計には収入を記録する場所が無かった（残課題 R-9）。

収入は支出と違い、件数が少ない（給与など月に数件）。
カードの利用通知メールのような、自動で取り込める元も決まっていない。

## 選択肢

1. スマホアプリから手で入力する
2. Discord の bot に送る（例: `+給与 250000`）
3. 給与明細や入金通知のメールを自動で取り込む

## 決定

1 を採用する。収入は支出とは別の記録（`incomes`）として持ち、スマホアプリから追加・修正・削除する。

## 結果

- 月に数件の入力なので、手で入れても「続けられるか」を損なわない。
- 支出の記録には手を入れない。アプリから支出を追加できない方針（二重登録を防ぐため）はそのまま残る。収入には自動の入口が無いので、アプリから追加しても二重登録は起きない。
- bot の書き方に収入の記法を足さずに済む。金額だけ送る `800` が支出か収入か紛れることもない。
- 給与のように毎月入る収入も、毎月入力する必要がある。定期的な収入を自動で記録するかは残課題 R-11 で扱う。
- 入金通知メールの自動取り込みは、対応する銀行と見本のメールが揃ってから検討する。
