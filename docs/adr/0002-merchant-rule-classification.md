# ADR-0002: 自動分類は店名ルールのみで行う

- 状態: 採用
- 日付: 2026-09-30

## 背景

カード・QR決済の店名や、bot に送ったメモからカテゴリを自動で決める方法を決める必要があった（README「未決定」）。

## 選択肢

1. 店名ルールのみ（直した店を学習する）
2. 店名ルールで分類し、当たらないものだけ生成AIで推定する
3. 生成AIのみ

## 決定

1 を採用する。店名・メモを正規化したキーの**完全一致**でルールを引き、当たらなければ確認待ちにする。
アプリや Discord のリアクションでカテゴリを選んだときに、そのキーのルールを作成または上書きする。

## 結果

- 同じ店は常に同じカテゴリになり、結果を予測できる。単体テストで期待値が一意に決まる。
- 外部 API の費用・キー管理・障害の影響を受けない。
- 使い始めは確認待ちが多くなる。直した店は次から自動で分類されるので、使うほど減る（README の「使うほど確認は減っていく」）。
- 部分一致をしないため、`セブン-イレブン 渋谷店` と `セブン-イレブン 新宿店` は別の店として扱われる。
  支店名の扱いは、送り主ごとの解析器で店名をどこまで取り出すかで調整する。
